  operator step). Inside the pod the node sees only its pod IP, so peers learn

  through hole-punching and relays. Off-cluster, against the same keystore:

{{- else if and (eq $type "NodePort") (not .Values.service.nodePort) }}

     NODE_PORT=$(kubectl -n {{ $ns }} get svc {{ $name }} -o jsonpath='{.spec.ports[0].nodePort}')
{{- end }}

     # Not registered yet: stake and register with the address.
     decdn setup{{ $flags }}
     # Already registered: replace the whole registered set (the node must be
     # active, and a cooldown applies between updates).
     decdn node update-multiaddrs{{ $flags }}

  Without --multiaddr, `decdn setup` registers the public address of the
  machine it runs on (if it has one), which is not this node's.
